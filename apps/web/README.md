# Conver Pay Web

Authenticated product UI for Conver Pay.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- hand-authored CSS based exclusively on the repository root `DESIGN.md`

No Tailwind or generic dashboard component kit is used. The root `DESIGN.md` is the visual source of truth.

## Development

```bash
npm install
npm run dev
```

## Gates

```bash
npm run lint
npm run build
```
